# SOMA

Uma página sobre pequenos hábitos e uma rotina mais equilibrada, com uma demonstração interativa para acompanhar as atividades do dia.

**[Acesse o site](https://osamuelz.github.io/soma/)** · **[Veja o repositório](https://github.com/osamuelz/soma)**

## O que você pode fazer

- Marcar e desmarcar hábitos concluídos.
- Adicionar e remover hábitos, com limite de seis por dia.
- Acompanhar o progresso da sua lista.
- Manter os hábitos salvos no navegador. As marcações são reiniciadas quando o dia muda.

## Tecnologias

HTML, CSS e JavaScript puro. Sem frameworks ou instalação de dependências.

## Como executar

Clone o repositório e abra o arquivo `index.html` no navegador:

```bash
git clone https://github.com/osamuelz/soma.git
cd soma
```

Se preferir um servidor local, execute na pasta do projeto:

```bash
python -m http.server 8000
```

Depois, acesse `http://localhost:8000`.

## Sobre o projeto

SOMA é um projeto fictício de portfólio. A demonstração funciona no próprio navegador, sem conta de usuário ou sincronização em nuvem. Os dados ficam no armazenamento local do navegador utilizado.

Publicado no GitHub Pages a partir da branch `main`.
